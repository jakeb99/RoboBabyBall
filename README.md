# Robobaby Ball: Project Cradle
_Robobaby Ball: Project Cradle_ is a sci-fi puzzle platformer created in Unreal Engine 5, inspired by Super Monkey Ball. Players will explore six unique levels, navigating challenging environments, collecting points, and battling enemies using their _Cradle's_ rocket launcher. Core gameplay systems created using Blueprints include: a checkpoint system, dynamic difficulty scaling, a health system, an ability shop, and enemy AI. Replayability is achieved through a high score system, encouraging players to master each level.
